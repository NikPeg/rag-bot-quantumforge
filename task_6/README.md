# Задание 6: Автоматическое ежедневное обновление базы знаний

## Описание

Это задание реализует полностью автоматизированный процесс обновления базы знаний: скачивание новых документов, преобразование их в чанки, обновление векторного индекса и логирование. Система отслеживает изменения в исходных документах и автоматически синхронизирует векторный индекс.

## Функциональность

### Основные возможности

1. **Автоматическое сканирование** источника данных (`knowledge_base/`)
2. **Отслеживание изменений** с помощью хеширования файлов (SHA256)
3. **Инкрементальное обновление** — обрабатываются только новые и изменённые файлы
4. **Удаление устаревших данных** — автоматическое удаление чанков из удалённых файлов
5. **Подробное логирование** всех операций с временными метками
6. **Сохранение состояния** между запусками для эффективного отслеживания изменений

### Источник данных

По умолчанию используется локальная папка `knowledge_base/`, но система легко адаптируется для других источников:
- S3-бакет
- Публичный Git-репозиторий
- RSS-фид
- Google Drive
- Любой другой источник, доступный через файловую систему

## Использование

### Ручной запуск

```bash
# Запустите скрипт обновления вручную
python update_index.py
```

Скрипт выполнит следующие действия:
1. Загрузит предыдущее состояние индекса (если есть)
2. Просканирует `knowledge_base/` на наличие изменений
3. Обработает новые и изменённые файлы
4. Обновит векторный индекс в ChromaDB
5. Сохранит новое состояние и запишет логи

### Автоматический запуск через cron

#### macOS / Linux

```bash
# Запустите скрипт настройки cron
./setup_cron.sh
```

Скрипт:
- Определит путь к Python (виртуальное окружение или системный)
- Добавит задачу в crontab для ежедневного запуска в 6:00
- Настроит логирование в `logs/cron.log`

#### Ручная настройка cron

```bash
# Откройте crontab для редактирования
crontab -e

# Добавьте строку (замените пути на ваши):
0 6 * * * /path/to/.venv/bin/python /path/to/task_6/update_index.py >> /path/to/task_6/logs/cron.log 2>&1
```

#### Расписание cron

Формат: `минута час день_месяца месяц день_недели`

Примеры:
- `0 6 * * *` — каждый день в 6:00
- `0 */6 * * *` — каждые 6 часов
- `0 0 * * 0` — каждое воскресенье в полночь
- `*/30 * * * *` — каждые 30 минут

## Состояние индекса

Файл `index_state.json` хранит состояние индекса между запусками:

```json
{
  "file_hashes": {
    "/path/to/knowledge_base/document1.md": "abc123...",
    "/path/to/knowledge_base/document2.md": "def456..."
  },
  "last_update": "2025-01-17T06:00:10.123456",
  "last_stats": {
    "added_chunks": 5,
    "deleted_chunks": 0,
    "total_chunks_before": 4509,
    "total_chunks_after": 4514
  }
}
```

Этот файл позволяет:
- Отслеживать изменения файлов без полного пересканирования
- Восстанавливать состояние после сбоев
- Анализировать историю обновлений

## Обработка ошибок

Скрипт обрабатывает следующие ситуации:

1. **Отсутствие индекса** — создаётся новый индекс
2. **Ошибки загрузки файлов** — файл пропускается, ошибка логируется
3. **Ошибки генерации эмбеддингов** — процесс останавливается с ошибкой
4. **Ошибки обновления БД** — критическая ошибка, процесс останавливается
5. **Ошибки сохранения состояния** — предупреждение, но процесс продолжается

### Коды возврата

- `0` — успешное выполнение
- `1` — ошибка выполнения

## Устранение неполадок

### Проблема: Индекс не обновляется

**Решение:**
1. Проверьте права доступа к `knowledge_base/` и `task_3/chroma_db/`
2. Проверьте логи на наличие ошибок
3. Убедитесь, что файлы действительно изменились (проверьте хеши)

### Проблема: Cron не запускается

**Решение:**
1. Проверьте, что cron запущен: `ps aux | grep cron`
2. Проверьте логи cron: `cat logs/cron.log`
3. Проверьте crontab: `crontab -l`
4. Убедитесь, что пути в crontab абсолютные

### Проблема: Ошибки при генерации эмбеддингов

**Решение:**
1. Проверьте установку `sentence-transformers`: `pip list | grep sentence`
2. Проверьте доступность модели: `python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2')"`
3. Проверьте свободное место на диске
