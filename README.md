# rag-bot-quantumforge
Создание AI-ассистента для компании QuantumForge Software на основе технологии RAG. Бот будет работать с корпоративной базой знаний, сокращать время поиска информации, выявлять пробелы в документации и улучшать её качество. Задача — автоматизировать ответы на запросы сотрудников и повысить продуктивность работы.
