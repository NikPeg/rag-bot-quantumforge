# RAG-бот для QuantumForge Software

Проект по созданию интеллектуального RAG-бота для работы с корпоративной базой знаний. Бот использует технологию Retrieval-Augmented Generation (RAG) для поиска информации в векторной базе данных и генерации ответов с использованием LLM.

## О проекте

RAG-бот предназначен для автоматизации ответов на вопросы сотрудников компании, сокращения времени поиска информации и выявления пробелов в документации. Система включает полный цикл: от исследования моделей и подготовки базы знаний до развёртывания Telegram-бота с автоматическим обновлением индекса.

## Структура проекта

Проект состоит из 8 заданий, каждое из которых реализует определённый этап разработки:

- **[Задание 1: Исследование моделей и инфраструктуры](./task_1/)** — анализ LLM, моделей эмбеддингов, векторных БД и выбор оптимальной конфигурации
- **[Задание 2: Подготовка базы знаний](./knowledge_base/)** — создание уникальной базы знаний с заменой терминов для тестирования RAG
- **[Задание 3: Создание векторного индекса](./task_3/)** — индексация базы знаний с использованием ChromaDB и sentence-transformers
- **[Задание 4: Реализация RAG-бота](./task_4/)** — создание RAG-пайплайна с техниками Few-shot и Chain-of-Thought
- **[Задание 5: Запуск и демонстрация работы бота](./task_5/)** — тестирование безопасности и демонстрация работы бота
- **[Задание 6: Автоматическое обновление базы знаний](./task_6/)** — настройка автоматического инкрементального обновления индекса
- **[Задание 7: Аналитика покрытия и качества](./task_7/)** — оценка полноты базы знаний и выявление пробелов
- **[Задание 8: Telegram RAG-бот](./task_8/)** — развёртывание бота в Telegram с Docker-контейнеризацией

## Технологический стек

- **LLM**: YandexGPT (через HTTP API)
- **Эмбеддинги**: sentence-transformers/all-MiniLM-L6-v2
- **Векторная БД**: ChromaDB
- **Фреймворк**: LangChain
- **Telegram**: aiogram 3.24.0
- **Контейнеризация**: Docker, Docker Compose
