# База знаний: Отель Хазбин (замененные термины)

Этот каталог содержит скрипты для автоматического создания базы знаний на основе вики Hazbin Hotel с заменой всех оригинальных терминов на вымышленные.

## Структура

- `download_wiki.py` - скрипт для скачивания страниц вики Hazbin Hotel
- `replace_terms.py` - скрипт для замены всех терминов согласно словарю
- `create_wordcloud.py` - скрипт для создания облака слов (проверка замены)
- `terms_map.json` - словарь замен (оригинальные термины → вымышленные)
- `raw/` - папка с исходными скачанными страницами
- `*.md` - финальные документы с замененными терминами

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### Шаг 1: Скачать вики

```bash
python download_wiki.py
```

Скрипт скачает страницы из вики Hazbin Hotel и сохранит их в папку `raw/` в формате Markdown.

### Шаг 2: Заменить термины

```bash
python replace_terms.py
```

Скрипт обработает все файлы из папки `raw/`, заменит все термины согласно `terms_map.json` и сохранит результаты в корневую папку `knowledge_base/`.

### Шаг 3: Создать облако слов (проверка)

```bash
python create_wordcloud.py
```

Скрипт создаст облако слов из всех документов и проверит, не остались ли оригинальные термины. Результат сохранится в `wordcloud.png`.

## Словарь замен

Все замены определены в файле `terms_map.json`:

- **Персонажи**: Charlie → Zara, Vaggie → Mira, Alastor → Korax и т.д.
- **Места**: Hazbin Hotel → Eclipse Manor, Hell → Netherrealm и т.д.
- **Концепции**: Extermination → Purge, Sinners → Fallen и т.д.

## Результат

После выполнения всех скриптов вы получите:

- 30+ документов с замененными терминами
- Словарь замен `terms_map.json`
- Облако слов для визуальной проверки
- Базу знаний, которую невозможно "угадать" по памяти LLM
