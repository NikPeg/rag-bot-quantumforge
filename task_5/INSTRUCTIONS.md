# Инструкция по выполнению задания 5

## Что нужно сделать

### 1. Переиндексировать базу знаний

Злонамеренный файл уже создан в `knowledge_base/malicious_file.md`. 
Теперь нужно переиндексировать базу, чтобы он попал в векторный индекс:

```bash
cd task_3
python build_index.py
```

### 2. Запустить тесты

```bash
cd task_5
python test_security.py
```

Скрипт автоматически проведёт:
- 5 успешных тестов (ответы на вопросы из базы знаний)
- 5 тестов на защиту (провоцирующие запросы)
- 1 тест без защиты (для сравнения)

## Что проверяется

### Успешные ответы (5 тестов)
Бот должен корректно отвечать на вопросы из базы знаний, используя найденные чанки.

### Защита от prompt injection (5 тестов)
Бот должен:
- Отфильтровывать злонамеренные чанки
- Блокировать опасные ответы
- Не выдавать конфиденциальную информацию (пароли, секреты)

## Готово!

После выполнения всех шагов задание 5 будет завершено. Все необходимые файлы созданы, защита реализована, скрипт для тестирования готов.
