### Краткие выводы

#### Выбранная конфигурация

**Рекомендуемое решение:**
- **LLM**: Xiaomi MiMo-V2-Flash (через OpenRouter) — **БЕСПЛАТНО**
- **Эмбеддинги**: sentence-transformers/all-MiniLM-L6-v2 (локально)
- **Векторная БД**: ChromaDB
- **Сервер**: Yandex Cloud Compute (8 vCPU, 32 GB RAM)

**Альтернативные варианты:**
- **YandexGPT Pro**: Если критична поддержка русского языка и обработка данных в России
- **Google Gemini 2.5 Flash**: Оптимальный баланс скорости (~1.9 сек) и стоимости ($0.0003/запрос)
- **DeepSeek V3.2**: Максимальная экономия ($0.000054/запрос), но медленное (~8 сек)

#### Результаты практического тестирования

Протестировано 5 моделей через OpenRouter API:

| Модель | Время (с) | Стоимость/запрос | Доступность из РФ |
|--------|-----------|------------------|-------------------|
| Xiaomi MiMo-V2-Flash | 4.53 | **$0.000000** | ✅ |
| Google Gemini 2.5 Flash | 1.88 | $0.000287 | ✅ |
| Google Gemini 3 Flash Preview | 1.83 | $0.000362 | ✅ |
| Claude Sonnet 4.5 | 4.55 | $0.003351 | ✅ |
| DeepSeek V3.2 | 7.97 | **$0.000054** | ✅ |

**Ключевые выводы:**
1. Все протестированные модели доступны из РФ через OpenRouter API
2. Xiaomi MiMo-V2-Flash — полностью бесплатная модель с хорошим качеством
3. Google Gemini 2.5 Flash — оптимальный выбор для продакшена (быстро + дёшево)
4. Рекомендуется иметь fallback на YandexGPT для гарантированной доступности

#### Выбранная векторная БД

**ChromaDB** — выбран как основная векторная БД по следующим причинам:
- ✅ Встроенная поддержка метаданных (критично для трассировки источников)
- ✅ Простота использования и интеграции с LangChain
- ✅ Автоматическая персистентность
- ✅ Достаточная производительность для текущего объёма данных (200,000-300,000 чанков)

**Альтернатива:** FAISS — быстрее, но требует ручной работы с метаданными

#### Конфигурация сервера

**Рекомендуемая конфигурация:**
- **CPU**: 8-16 ядер
- **RAM**: 32 GB (с запасом для роста)
- **GPU**: не требуется (используем облачные LLM)
- **Диск**: 100 GB SSD
- **Стоимость**: ~$200-300/мес (Yandex Cloud)
