## Задание 4. Реализация RAG-бота с техниками промптинга

### Отчёт

Реализован полнофункциональный RAG-бот с применением техник промптинга: Few-shot и Chain-of-Thought (CoT). Бот успешно интегрирован с векторной базой знаний и YandexGPT API.

### Реализованные компоненты

**Основной модуль RAG-бота** (`rag_bot.py`):
- ✅ Загрузка векторного индекса из ChromaDB (создан в задании 3)
- ✅ Поиск релевантных чанков по запросу пользователя
- ✅ Интеграция с YandexGPT через HTTP API
- ✅ Формирование промптов с Few-shot примерами и Chain-of-Thought
- ✅ Обработка ошибок и случаев отсутствия информации

**Техники промптинга:**

1. **Few-shot prompting**:
   - Автоматическое извлечение 1-2 примеров вопросов-ответов из базы знаний
   - Примеры выбираются на основе релевантности к типичным запросам
   - Показывают модели желаемый формат ответа

2. **Chain-of-Thought (CoT)**:
   - Пошаговое рассуждение перед ответом
   - Модель показывает, как она анализирует контекст
   - Формат: "[Рассуждение] 1. Ищу... 2. В документе найдено... 3. Следовательно..."
   - Можно включать/отключать через параметр `use_cot`

### Архитектура RAG-пайплайна

Процесс обработки запроса состоит из следующих этапов:

1. **Загрузка индекса**: Векторный индекс загружается из ChromaDB
2. **Поиск релевантных чанков**: Запрос преобразуется в эмбеддинг, ищутся ближайшие чанки (топ-5)
3. **Формирование промпта**:
   - System prompt с инструкциями и правилами
   - Few-shot примеры (1-2 примера из базы знаний)
   - Контекст (найденные чанки с указанием источников)
   - Запрос пользователя
4. **Генерация ответа**: Промпт отправляется в YandexGPT
5. **Возврат результата**: Ответ возвращается с указанием источников и метаданных

### Используемые технологии

- **Векторная БД**: ChromaDB (индекс из задания 3)
- **Модель эмбеддингов**: `sentence-transformers/all-MiniLM-L6-v2`
- **LLM**: YandexGPT (базовая версия, через HTTP API)
- **Библиотеки**: LangChain, ChromaDB, requests
