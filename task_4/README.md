# Задание 4: Реализация RAG-бота с техниками промптинга

## Описание

Это задание реализует полнофункциональный RAG-бот, который:
- Ищет информацию в векторной базе знаний
- Формирует ответы с опорой на найденные данные
- Применяет техники улучшения качества ответа: **Few-shot** и **Chain-of-Thought (CoT)**

## Используемые технологии

- **Векторная БД**: ChromaDB (индекс из задания 3)
- **Модель эмбеддингов**: `sentence-transformers/all-MiniLM-L6-v2`
- **LLM**: YandexGPT (через HTTP API)
- **Техники промптинга**:
  - **Few-shot prompting**: 1-2 примера из базы знаний
  - **Chain-of-Thought (CoT)**: пошаговое рассуждение перед ответом

## Архитектура

RAG-пайплайн состоит из следующих этапов:

1. **Загрузка индекса**: Векторный индекс загружается из ChromaDB (создан в задании 3)
2. **Поиск релевантных чанков**: Запрос пользователя преобразуется в эмбеддинг и ищутся ближайшие чанки
3. **Формирование промпта**:
   - System prompt с инструкциями
   - Few-shot примеры (1-2 примера из базы знаний)
   - Контекст (найденные чанки)
   - Запрос пользователя
4. **Генерация ответа**: Промпт отправляется в YandexGPT для генерации ответа
5. **Возврат результата**: Ответ возвращается пользователю с указанием источников

## Техники промптинга

### Few-shot prompting

Бот использует 1-2 примера вопросов-ответов из базы знаний, чтобы показать модели желаемый формат ответа:

```
Пример 1:
Q: Как называется столица планеты Ти'лора?
A: Столица планеты Ти'лора называется Сайрон...

Пример 2:
Q: Кто такой Korax?
A: Korax — это могущественный персонаж...
```

Примеры автоматически извлекаются из базы знаний на основе релевантности.

### Chain-of-Thought (CoT)

Бот просит модель показать свои рассуждения перед ответом:

```
[Рассуждение]
1. Ищу в контексте информацию о...
2. В документе [номер] найдено...
3. Следовательно, ответ...

[Ответ]
Твой ответ здесь
```

Это помогает модели:
- Лучше анализировать контекст
- Снизить риск галлюцинаций
- Повысить прозрачность ответа

## Использование

### Интерактивный режим (REPL)

```bash
python rag_bot.py
```

После запуска вы сможете задавать вопросы боту:

```
Вопрос: Что такое Eclipse Manor?
```

**Команды:**
- `exit` или `quit` - выход из программы
- `cot` - включить Chain-of-Thought (по умолчанию)
- `nocot` - отключить Chain-of-Thought

### Программное использование

```python
from rag_bot import RAGBot

# Инициализация бота
bot = RAGBot()

# Задать вопрос
result = bot.answer("Что такое Eclipse Manor?", use_cot=True)

if result["success"]:
    print(result["answer"])
    print(f"Источники: {result['sources']}")
else:
    print(f"Ошибка: {result['error']}")
```

## Классы и методы

### `RAGBot`

Основной класс RAG-бота.

**Методы:**
- `__init__()` - инициализация бота
- `search(query, k=5)` - поиск релевантных чанков
- `answer(query, use_cot=True)` - генерация ответа на вопрос

### `YandexGPTClient`

Клиент для работы с YandexGPT API.

**Методы:**
- `__init__(model, api_key)` - инициализация клиента
- `generate(messages, temperature, max_tokens)` - генерация ответа

## Параметры конфигурации

В файле `rag_bot.py` можно настроить:

- `INDEX_DIR` - путь к директории с индексом ChromaDB
- `EMBEDDING_MODEL` - модель эмбеддингов
- `DEFAULT_MODEL` - модель LLM по умолчанию
- `TOP_K_CHUNKS` - количество чанков для поиска (по умолчанию 5)

## Обработка ошибок

Бот корректно обрабатывает следующие ситуации:

1. **Индекс не найден**: Выводит понятное сообщение об ошибке
2. **Нет релевантных чанков**: Честно отвечает "Я не знаю"
3. **Ошибка API YandexGPT**: Выводит детали ошибки
4. **Проблемы с авторизацией**: Подсказывает, как настроить yc CLI
