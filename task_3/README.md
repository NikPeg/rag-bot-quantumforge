# Задание 3: Создание векторного индекса базы знаний

## Описание

Это задание реализует создание векторного индекса для базы знаний, подготовленной в задании 2. Индекс создаётся с использованием ChromaDB и модели эмбеддингов `sentence-transformers/all-MiniLM-L6-v2`.

## Используемые технологии

- **Модель эмбеддингов**: `sentence-transformers/all-MiniLM-L6-v2`
  - Размерность: 384
  - Размер модели: ~22 МБ
  - Скорость: ~5-10 мс на CPU для короткого предложения
  - Репозиторий: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2

- **Векторная БД**: ChromaDB
  - Встроенная поддержка метаданных
  - Автоматическая персистентность
  - Простая интеграция с LangChain

## Параметры индексации

- **Размер чанка**: 500 токенов
- **Overlap**: 100 токенов (20% перекрытия)
- **Разделители**: `\n\n`, `\n`, `. `, ` `, `""`

## Метаданные

Каждый чанк содержит следующие метаданные:
- `source`: полный путь к исходному файлу
- `file_name`: имя файла
- `chunk_index`: порядковый номер чанка в документе
- `total_chunks`: общее количество чанков в документе

```bash
python -m venv .venv
source .venv/bin/activate  # на Windows: .venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```

## Использование

```bash
# Запустите скрипт создания индекса
python build_index.py
```

Скрипт выполнит следующие шаги:
1. Загрузит все `.md` документы из `knowledge_base/` (исключая папку `raw`)
2. Разобьёт документы на чанки с сохранением метаданных
3. Сгенерирует эмбеддинги для каждого чанка
4. Создаст векторный индекс в ChromaDB
5. Сохранит индекс на диск в папку `chroma_db/`
6. Выполнит тестовые запросы для проверки работы индекса

## Результат

После выполнения скрипта будет создана папка `chroma_db/` с векторным индексом. Индекс можно использовать для поиска релевантных фрагментов текста по пользовательским запросам.

## Пример использования индекса

### Использование готового скрипта

```bash
# После создания индекса можно использовать скрипт для поиска
python query_index.py
```

Скрипт `query_index.py` предоставляет:
- Примеры поиска по индексу
- Интерактивный режим для выполнения собственных запросов

### Программное использование

```python
try:
    from langchain_huggingface import HuggingFaceEmbeddings
except ImportError:
    from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_community.vectorstores import Chroma

# Загрузите индекс
embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
vectorstore = Chroma(
    persist_directory="./chroma_db",
    embedding_function=embeddings
)

# Выполните поиск
results = vectorstore.similarity_search("Что такое Eclipse Manor?", k=3)
for doc in results:
    print(f"Файл: {doc.metadata['file_name']}")
    print(f"Текст: {doc.page_content[:200]}...")
```
